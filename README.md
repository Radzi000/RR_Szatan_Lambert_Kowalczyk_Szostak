# RR_Szatan_Lambert_Kowalczyk_Szostak
Repository containing a reproducible research of Quantitative Analysis of Intraday Momentum via Volatility Regimes, Trend Filtering, and Temporal Persistence


We base our work on this repo:
https://github.com/blackswan-quants/intraday-momentum

It contains algorithmic trading strategies, that we want to improve by:
1. Making it work locally (these strats are developed for the quantconnect platform).
2. We will improve the strategies via e.g. better logic, parameter tuning (NES, CMA-ES), etc.
3. More and better evaluation metrics, trade dependency.
4. Nice visualisations.
