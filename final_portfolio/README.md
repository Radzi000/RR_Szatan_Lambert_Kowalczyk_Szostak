# Final Portfolio

This directory is reserved for the final out-of-sample portfolio construction
layer of the project.

Planned portfolio families:

- equal-weight portfolios,
- Kelly-style allocations,
- Markowitz mean-variance allocations.

## Current Status

The verified Docker baseline does not depend on this directory yet. For now it
intentionally stays minimal so the repository remains clean.

## Future Role

This layer should eventually consume selected out-of-sample strategy results and
produce reproducible portfolio comparison artifacts.
